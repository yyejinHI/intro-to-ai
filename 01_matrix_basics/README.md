# 01. 행렬 곱으로 선형 모델 계산하기

MATLAB 행렬 연산으로 간단한 **선형 모델** `y = a*x + b` 를 계산해 보는 기초 예제입니다.
키(Height)로 몸무게(Weight)를 예측하는 식을 반복문 없이 행렬 곱 한 번으로 구합니다.

## 핵심 개념

- **상수항(bias) 열 추가** — 입력 `x` 옆에 1로 채운 열을 붙이면 `[x 1] * [a; b] = a*x + b` 가 되어, 기울기와 절편을 파라미터 벡터 하나로 묶을 수 있다.
- **행렬 곱 = 모든 데이터 한 번에 계산** — 6×2 행렬 × 2×1 벡터 = 6×1 예측값. 데이터가 몇 개든 코드는 같다.
- **오차(residual)** — `실제값 - 예측값`. 이 값을 작게 만드는 `[a; b]` 를 찾는 것이 뒤에서 배우는 회귀(regression)이다.

## 파일 설명

| 파일 | 내용 |
|------|------|
| `linear_model_matrix.m` | 키 6개로 `[h 1]` 행렬 구성, 파라미터 `t = [0.2; 30]` 과 곱해 예측 몸무게 `OUT` 계산, `Weight - OUT` 으로 오차 출력 |

## 핵심 코드

```matlab
Height(:,1) = [160; 165; 170; 175; 180; 185];
Height(:,2) = ones(length(Height(:,1)), 1);   % 상수항용 1 열
t = [0.2; 30];                                % y = 0.2*h + 30
OUT = Height * t;                             % 6x2 * 2x1 = 6x1
Weight - OUT                                  % 오차
```

## 결과

| Height | Weight (실제) | OUT (예측) | 오차 |
|--------|---------------|------------|------|
| 160 | 62 | 62 | 0 |
| 165 | 63 | 63 | 0 |
| 170 | 64 | 64 | 0 |
| 175 | 65 | 65 | 0 |
| 180 | 66 | 66 | 0 |
| 185 | 67 | 67 | 0 |

이 데이터는 정확히 `0.2*h + 30` 위에 놓여 있어 오차가 모두 0입니다.
